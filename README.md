## Установка

1. Скачай `quick.exe`
2. Получи API-ключ Gemini (инструкция ниже в разделе «Как получить ключ»)
3. Создай файл `key.txt` и положи туда ключ **без пробелов и энтеров**
4. Запусти `quick.exe`

Если качал на флешку: воткни её, запусти Quick и вынь флешку. Он сам всё подгрузит в оперативку.

⚠️ **Если качал напрямую, удали файл после запуска из загрузок!**

В углу должно появиться окошко с комбинациями клавиш. Значит, всё работает.

## Как получить ключ Gemini

1. Открой сайт https://aistudio.google.com/apikey и войди в свой Google-аккаунт
2. Нажми кнопку создания ключа (**Create API key**)
3. Выбери проект или создай новый, и подтверди
4. Скопируй появившийся ключ. Это одна длинная строка, обычно начинается с `AIza`
5. Вставь её в `key.txt` без пробелов и переносов строки

⚠️ **Никому не показывай свой ключ и не выкладывай его в открытый доступ.** Иначе другие смогут тратить твои лимиты.

## Управление

Все комбинации делаются с **Alt + Ctrl**. Ниже указана только последняя буква (например, Alt+Ctrl+R).

**Всё управление идёт через клавиши. Само окно не ловит нажатия мыши!**

| Клавиша | Что делает |
|---|---|
| **W A S D** | Перемещение курсора по окну |
| **E** | Поставить метку. Листаешь курсором куда надо, ставишь метку, и от неё идёт выделение (выделенное становится серым) |
| **Q** | Скрыть окно |
| **X** | Удалить. Использовать только в самом конце, иначе программу придётся заново запускать через exe |
| **T** | Переключить тему. Если буквы не видно или они плывут, поменяй. При запросе ответа тема под окно меняется автоматически |
| **R** | **Самое важное: запрос ответа.** Писать ничего не надо, программа сама делает скрин и отправляет ИИ |
