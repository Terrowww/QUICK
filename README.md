# Quick на ПК

## [Скачать quick.exe](https://github.com/Terrowww/terrowww-pc/releases/latest)

### Также есть мобильная версия: [Quick на Android](https://github.com/Terrowww/terrowww-mb)


## Установка

1. Скачай `quick.exe`
2. Создай файл `key.txt` и положи туда ключ без пробелов и энтеров (ключ пришлю отдельно)
3. Запусти `quick.exe`

Если качал на флешку: воткни её, запусти Quick и вынь флешку. Он сам всё подгрузит в оперативку.

В углу должно появиться окошко с комбинациями клавиш. Значит, всё работает.

## Управление

Все комбинации делаются с Alt + Ctrl. Ниже указана только последняя буква (например, Alt+Ctrl+R).

Всё управление идёт через клавиши. Само окно не ловит нажатия мыши.

| Клавиша | Что делает |
|---|---|
| R | Запрос ответа. Писать ничего не надо |
| W A S D | Перемещение курсора по окну |
| E | Поставить метку. Листаешь курсором куда надо, ставишь метку, и от неё идёт выделение (выделенное становится серым) |
| C | Копировать выделенное |
| Q | Скрыть окно |
| T | Переключить тему. Если буквы не видно или они плывут, поменяй. При запросе ответа тема под окно меняется автоматически |
| X | Выход. Использовать только в самом конце, иначе программу придётся заново запускать через exe |

## После использования

> [!IMPORTANT]
> 1. Нажми X, чтобы закрыть программу
> 2. Удали `quick.exe` и `key.txt` через Shift+Delete
> 3. Ctrl+J → убери запись о скачивании
